# AKGEC Backend

This directory contains the Express.js API, MongoDB connector, RAG AI services, and persistent JSON storage for AKGEC.

For the full setup instructions, architectural overview, and future roadmap, please refer to the main project documentation:
👉 [**Root README.md**](../README.md)

### Quick Commands:
```bash
npm install    # Install dependencies
npm start      # Launch AKGEC API server on port 5000
```
